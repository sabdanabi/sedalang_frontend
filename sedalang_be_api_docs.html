Dokumentasi API & Skema Database Sedalang (untuk FE)

Halaman ini berisi peta lengkap endpoint API backend sedalang_be beserta skema database Prisma untuk mempermudah pengerjaan frontend.

1. Ringkasan Endpoint API

Modul: Auth (/auth, /users)

POST /auth/register

Deskripsi: Register user baru (default role: USER)

Request Body (JSON):

{
  "email": "string (email, required)",
  "password": "string (min 6 chars, required)",
  "fullName": "string (required)"
}

Response (201): JWT Token { "token": "string" }

POST /auth/login

Deskripsi: Login dengan email & password

Request Body (JSON):

{
  "email": "string (email, required)",
  "password": "string (required)"
}

Response (200): JWT Token { "token": "string" }

GET /users/me

Headers: Authorization: Bearer <JWT>

Deskripsi: Dapatkan data profil user yang sedang login

Response (200): Detail user (termasuk role, avatarUrl, dll)

PATCH /users/me

Headers: Authorization: Bearer <JWT>

Content-Type: multipart/form-data

Deskripsi: Update data profil user (termasuk upload avatar)

Multipart Fields:

  • fullName: string (optional)
  • phoneNumber: string (optional)
  • address: string (optional)
  • latitude: float (optional)
  • longitude: float (optional)
  • avatar: file (optional, image)
PATCH /users/me/role

Headers: Authorization: Bearer <JWT>

Deskripsi: Update role user saat onboarding (USER atau CRAFTSMAN)

Request Body: { "role": "USER" | "CRAFTSMAN" }

Response (200): Mengembalikan token JWT baru

Modul: Onboarding (/onboarding)

POST /onboarding/craftman

Headers: Authorization: Bearer <JWT>

Content-Type: multipart/form-data

Deskripsi: Onboarding pengrajin — isi data craftsman, opsional upload portofolio

Multipart Fields:

  • location: string (required)
  • latitude: float (required)
  • longitude: float (required)
  • skills: array of string (di-serialize / dikirim terpisah)
  • craftType: string (required)
  • portfolios: files (optional, max 5 images)

Response (200): Token baru dengan role CRAFTSMAN

POST /onboarding/skip

Headers: Authorization: Bearer <JWT>

Deskripsi: Melewati onboarding, user tetap berstatus sebagai user biasa

Modul: Craftsmen (/craftsmen)

GET /craftsmen

Query Parameters:

  • page: number (default 1)
  • limit: number (default 10)
  • search: string (nama/kerajinan)
  • skill: string (filter keahlian)
  • location: string (filter lokasi)
  • minRating: number (0-5)
  • sortBy: "rating" | "newest" | "name" (default "rating")

Response (200): Array of craftsmen + pagination metadata

GET /craftsmen/filters

Deskripsi: Data dropdown filter: daftar unik skills dan locations yang tersedia di database.

GET /craftsmen/match/:ideaId

Headers: Authorization: Bearer <JWT>

Deskripsi: Auto-match pengrajin terdekat/terbaik berdasarkan skill yang dibutuhkan dari suatu ide AI

POST /craftsmen/search

Headers: Authorization: Bearer <JWT>

Deskripsi: Cari pengrajin manual berdasarkan koordinat jarak terdekat dan kemiripan keahlian

Request Body (JSON):

{
  "query": "string (optional)",
  "skills": ["string (optional)"],
  "latitude": 0.0,
  "longitude": 0.0
}
GET /craftsmen/:id

Deskripsi: Lihat profil publik pengrajin berdasarkan ID-nya

PATCH /craftsmen/me

Role: CRAFTSMAN

Request Body (JSON):

{
  "location": "string (optional)",
  "latitude": 0.0,
  "longitude": 0.0,
  "skills": ["string"],
  "craftType": "string"
}
POST /craftsmen/me/portfolios

Role: CRAFTSMAN, multipart/form-data

Multipart Fields: images (multiple files, max 5)

DELETE /craftsmen/me/portfolios

Role: CRAFTSMAN

Request Body (JSON): { "url": "string (url gambar portofolio)" }

Modul: AI (/ai)

POST /ai/analyze-ideas

Headers: Authorization: Bearer <JWT>

Content-Type: multipart/form-data

Multipart Fields:

  • image: file (required, image)
  • description: string (optional)

Response (201): Mengembalikan objek analisis material dan list 3 rekomendasi ide.

GET /ai/history

Deskripsi: Riwayat analisis AI milik user

Modul: Chat & Proposal (/chat)

POST /chat/rooms

Headers: Authorization: Bearer <JWT>

Request Body (JSON):

{
  "craftsmanId": "string (uuid, required)",
  "ideaId": "string (uuid, optional, bisa kosong untuk chat non-ide)"
}

Response (201): Mengembalikan objek ChatRoom

GET /chat/rooms

Deskripsi: Daftar semua chat room milik user (baik sebagai user biasa maupun pengrajin)

GET /chat/rooms/:roomId/messages

Deskripsi: Histori pesan dalam chat room

POST /chat/rooms/:roomId/proposals

Role: CRAFTSMAN

Request Body (JSON):

{
  "productName": "string (required)",
  "price": 150000,
  "materialsNeeded": ["paku", "cat"],
  "deliveryMethod": "GOSEND" | "DROP_OFF",
  "estimatedCompletionDate": "2026-09-15 (ISO date string)",
  "paymentMethod": "string (e.g. BANK_TRANSFER)",
  "bankName": "BCA (optional)",
  "bankAccountNumber": "123 (optional)",
  "bankAccountName": "Budi (optional)"
}
PATCH /chat/proposals/:proposalId/accept

Role: USER

Deskripsi: User menerima proposal dan sistem otomatis men-generate Order dengan token pembayaran Midtrans.

PATCH /chat/proposals/:proposalId/reject

Role: USER

Deskripsi: Menolak proposal

Modul: Orders (/orders)

GET /orders

Deskripsi: Daftar semua order (buyer atau craftsman)

GET /orders/:orderId

Deskripsi: Detail order & progress timeline

POST /orders/:orderId/progress

Role: CRAFTSMAN

Request Body (JSON):

{
  "title": "string",
  "description": "string",
  "status": "IN_PROGRESS" | "COMPLETED" (optional, untuk update status order sekaligus)
}
POST /orders/:orderId/media

Role: CRAFTSMAN, multipart/form-data

Multipart Fields: images (multiple files, max 5)

PATCH /orders/:orderId/status

Role: CRAFTSMAN

Request Body (JSON): { "status": "PENDING" | "PAID" | "IN_PROGRESS" | "COMPLETED" | "CANCELLED" }

POST /orders/:orderId/check-payment

Role: USER

Deskripsi: Manual trigger sync status pembayaran ke Midtrans.

POST /orders/retry/:proposalId

Role: USER

Deskripsi: Regenerate link Midtrans baru untuk proposal yang sudah accepted namun gagal/expired pembayarannya.

PATCH /orders/:orderId/rating

Role: USER

Request Body (JSON): { "rating": 1 sampai 5 }

2. WebSocket (Socket.io) Event

Dipakai untuk chat real-time. Koneksi membutuhkan token JWT di parameter auth.token.

  • Koneksi: Kirim token saat inisiasi socket connection: io(url, { auth: { token } })
  • Join Room: Emit event joinRoom dengan isi data roomId (string UUID) untuk mendengarkan pesan masuk di room tersebut.
  • Send Message: Emit event sendMessage dengan payload: 
    {
  "roomId": "string (uuid)",
  "content": "string (max 2000 chars)"
}
  • Mark Read: Emit event readMessages dengan payload roomId (string UUID) untuk menandai pesan-pesan sudah dibaca.
  • Event dari Server ke Client:
    • newMessage: payload berisi objek ChatMessage baru.
    • messagesRead: ter-trigger saat pesan ditandai telah dibaca.
    • newProposal: payload berisi objek Proposal baru.
    • proposalUpdated: status proposal berubah (accepted/rejected).
    • orderUpdated: status order/progress berubah.
    • authError / error: jika otentikasi gagal atau terjadi error lainnya.

idUuid (String)Primary Key

avatarUrlString (optional)Foto profil

FieldTipe DataKeterangan
idUuid (String)Primary Key

locationStringNama kota/kabupaten

FieldTipe DataKeterangan

ChatRoom & Proposal

Relasi unik: userId + craftsmanId + ideaId. Jika user langsung chat tanpa ide AI, ideaId bernilai null.

Proposal dibuat oleh pengrajin di dalam room untuk menawarkan pengerjaan barang.
